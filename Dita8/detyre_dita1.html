Detyra 2: Operatorët matematikorë

Krijo dy numra a dhe b. Shfaq mbledhjen, zbritjen, shumëzimin dhe pjesëtimin.

Detyra 3: if / else if / else

Krijo një variabël nota (1–5). Shfaq mesazh sipas notës.

Detyra 4: Loops

Detyra 5: Array dhe for...of
